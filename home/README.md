# 🏫 DreamSchool RP

Bienvenue à **DreamSchool**, le serveur FiveM **Roleplay scolaire** francophone ! 🎒✨

Ici, pas de police, pas d'EMS, pas de gangs : tout se passe **dans l'enceinte de l'établissement**. Vous y êtes élève, professeur, surveillant, membre de la direction ou du personnel, et vous vivez la vie d'une école du premier cours à la dernière sonnerie. 🔔

{% hint style="info" %}
🆓 **Accès libre** : pas de whitelist, tout le monde est le bienvenu tant que le règlement est respecté.
{% endhint %}

## 🚀 Rejoindre la communauté

💬 **Discord** : [discord.gg/dreamschoolfa](https://discord.gg/dreamschoolfa)

## 🧭 Comment lire ce règlement

Le règlement est divisé en plusieurs parties. **Lisez-les toutes** avant de jouer : elles s'appliquent à tout le monde, élèves comme professeurs.

### 📜 Les bases
- 📜 **Règles générales** : respect, comportement, staff, Discord
- 🎭 **Règles RP** : langage RP, réalisme, personnage

### 🏫 La vie de l'école
- 👥 **Rôles et personnel** : élèves, professeurs, surveillants, direction
- 🕒 **Vie scolaire** : horaires, retards, absences, tenue, téléphone
- 📚 **Règles en classe** : cours, prise de parole, contrôles
- 📍 **Lieux de l'établissement** : couloirs, cour, cantine, gymnase…
- 📝 **Examens et événements** : contrôles, conseils de classe, fêtes
- 🤝 **Conflits et harcèlement** : disputes, limites, consentement

### ⚖️ La discipline
- ⚖️ **Sanctions** : sanctions RP (en classe) et sanctions HRP (serveur)

{% hint style="warning" %}
⚠️ **Le règlement est à connaître avant de jouer.** Ne pas l'avoir lu ne vous exonère pas des sanctions.
{% endhint %}
